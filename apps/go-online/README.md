# 围棋学堂 Online V4.5 · 围棋算法实验室


## 新增：围棋算法实验室（V4.5）

这是与原五十课、方法论、自由人机、真人房间并列的**独立教学模块**。

- 大厅点击「围棋算法实验室」进入，无需账号或联网。
- 你执黑棋，电脑 AI 执白棋，明确显示“电脑 AI（非真人）”。
- 选择 9、13、19 路棋盘，以及入门或标准算法难度，点击重新开局生效。
- 单击空点预览，双击快速落子，也可用按钮确认。
- 棋盘显示高分合法候选点的热力图和前三名排名标记；热力图颜色仅表示**相对启发式分数**，不是胜率。
- 旁边算法老师分四步展示：扫描空点 → 规则过滤 → 模拟提子/救棋/叫吃并评分 → 从候选池选点。
- 可点各候选点查看**真实评分加减项**；每一步的得分总和与 AI 实际使用的评分一致。
- 电脑走完后，选择「AI 上一步」即可看到它实际选择的落点、分数细节，以及与其他候选点的比较。
- 入门 AI 从最多五个分散候选点中按可复现规则选一个，标准 AI 从最多两个中选择，并不保证每次选总分第一。
- 围棋老师支持左右切换，中英文均可用，手机上可通过按钮打开侧边讲解面板。
- 新模块不修改五十课的进度，也不影响已经开始的真人对局。

**重要**：当前算法是本地规则型、单步启发式评价器，不是深度读秒、Alpha-Beta 搜索、蒙特卡洛树搜索或神经网络。点位评分只是教学权重，不代表真实赢棋概率或全局最优性。算法的分数因子与程序源码在 `shared/goCoach.js` 完全一致。

## 原有功能概览

- 保留原有真人局域网对弈、自由人机、古风棋盘、老师左右切换、中文/English 切换。
- 将原来的 15 课扩展为 50 课（保留第 1–15 课原内容与原进度）。
- 新增 35 个棋形训练：竹节、虎口、一间跳、小飞、空三角、征子起手、枷形、双叫吃、弃子、眼形、星位、小目、挂角、夹击、侵消、官子等。
- 第 41–46 课为 13 路布局练习，第 47–48 课为 19 路布局练习；其余大多为 9 路棋形。
- 增加独立「围棋方法论」：16 个原创教学变化，可逐手前进/后退、自动播放、跳转手顺、复制 SGF 文本。
- 方法论无需登录、无需完成课程；它只演示固定的原创建议变化，不会更改真人棋局。
- 新课程英文讲义和方法论中英文说明均包含在源代码中。
- 现有前十五课完成记录通过浏览器 localStorage 迁移到 50 课版本（仍仅保存在本浏览器）。

## Linux 安装 / 更新

先在运行旧服务的终端按 `Ctrl+C`，再解压覆盖源码：

```bash
cd ~/Downloads
unzip -o weiqi-school-v4.5-algorithm-lab-linux.zip
cd go-online
./start.sh
```

以后仍可用之前设置的 `weiqi` 快捷命令。

本机网页：`http://localhost:3100`。
同一局域网手机访问：`http://你的Linux局域网IP:3100`。
若提示 3100 端口被占用，先停止旧围棋进程再重新启动。无需重装依赖（依赖未变）。

## 完整学习建议

1. 第一阶段：1–15 课复习数气、提子、接断、眼位与基础布局；之后学习 16–30 课的棋形与手筋。
2. 第二阶段：31–40 课理解死活、厚势和弃子取舍。
3. 第三阶段：41–50 课接触 13 / 19 路布局、挂角夹击、侵消与官子。
4. 在首页打开「围棋方法论」，挑选相关主题，逐手播放并读解说；可复制 SGF 到围棋棋谱软件中继续研究。
5. 在自由人机（9/13/19 路）实践，再与真人对局；定期复盘盲点。

**限度说明：** 50 课训练的目标是建立主流围棋概念与常见棋形的基础，而不是保证达到段位。老师和电脑是启发式算法，棋谱为原创教学示范，不保证职业级最优变化。
