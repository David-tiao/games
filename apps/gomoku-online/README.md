# 五子棋 Online · V1.1 跨设备版

React + Node.js + Socket.IO 五子棋联网工程。电脑、安卓手机和 iPhone 使用浏览器访问同一个地址即可对局。

## 一键启动（推荐）

Linux 项目目录下：

```bash
chmod +x start.sh
./start.sh
```

以后可继续使用之前配置的 `gomoku` 命令（只要它指向本项目的 `start.sh`）。

启动脚本会自动构建前端，并由 Node.js 服务在 **3001 单一端口**同时提供：
- 网页前端
- HTTP API
- Socket.IO 实时对局

## 手机和电脑一起玩（同一 Wi-Fi / 局域网）

1. Linux 主机运行 `./start.sh`。
2. 启动信息会打印一个局域网共用地址，例如 `http://10.50.88.249:3001`。
3. 主机电脑和手机都打开这个地址。
4. 双方分别注册不同账号并登录。
5. 一方创建私人房间，点击「分享邀请」或复制房间号；另一方打开邀请链接，或输入房间号加入。

**注意：**
- 所有设备必须能互相访问同一个局域网。手机连接与电脑相同的 Wi-Fi；不要使用访客 Wi-Fi，部分路由器会隔离无线设备。
- 不要在手机上输入 `localhost`；它代表手机自己。手机要输入 Linux 主机打印的局域网地址。
- 同一名玩家不要在两台设备上同时使用同一个账号；每位玩家使用各自账号。
- 如果 Linux 防火墙启用，放行唯一端口：

```bash
sudo ufw allow 3001/tcp
sudo ufw status
```

从手机先测试服务器是否可达：

```text
http://主机局域网IP:3001/api/health
```

如果显示包含 `"ok":true` 的 JSON，说明手机已连到服务器。然后打开不带 `/api/health` 的游戏地址。

## 不在同一 Wi-Fi 时

`10.x.x.x` 是局域网地址，不能直接从蜂窝网络或外部互联网访问。若要让异地朋友也能加入，需要把服务部署到有公网入口的服务器，或配置安全的 VPN/隧道，并建议使用 HTTPS/WSS。不要把开发服务器直接暴露到公网。

## 开发模式（仅开发时使用）

```bash
npm install
npm run dev
```

开发模式前端是 `http://localhost:5173`，API 和 Socket.IO 是 `http://localhost:3001`。生产/跨设备推荐使用上面的一键启动方式，只开放 3001 端口。

## 技术栈

- 前端：React、TypeScript、Vite
- 实时通信：Socket.IO
- 服务端：Node.js、Express
- 密码哈希：scrypt
- 账号持久化：JSON 文件
- 对局状态：服务器内存

## 第一版规则

- 15×15 棋盘，黑棋先手，白棋后手。
- 每步不限时。
- 服务端验证玩家身份、回合、落子范围和胜负条件。
- 横、竖、斜方向连续五子及以上获胜。
- 支持认输、离开、双方同意后再来一局。
- 支持邀请链接预填房间号、手机分享面板（浏览器支持时）。

## 数据保存说明

账号保存在 `server/data/users.json`；房间和正在进行的棋局保存在内存中。服务器重启后账号保留，但正在进行的房间会清空。
