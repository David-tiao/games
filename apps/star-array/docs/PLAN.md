# 星阵项目开发计划

## V0.1 单人核心原型（本次）
12 关、3 种棋盘、数学求解器、矩阵可视化、撤销重做、语言与主题设置、Linux 独立启动。

## V0.2 数学进阶
30 关、更多目标图案、逐步消元动画、解空间可视化、谜题编辑器。

## V0.3 十人协作
Node.js + Socket.IO 服务端房间，权威状态同步，操作序号及幂等校验，标记、投票撤销、断线重连、真人/AI 区分。

## V0.4 玩家账号和存档
SQLite + scrypt/Argon2id、会话管理、七天存档失效和清理、账号独立持久化；版本化迁移和测试。

## V1.0 验收
十人真实并发模拟、数据恢复、手机/桌面交互、负载、正式构建及打包。

> 设计目标不是承诺当前原型已经具备后续功能。每个版本须通过相应测试才能标记完成。
