# ✦ 星阵：共振计划 · STAR ARRAY V0.1

一款可在 Linux 本机直接启动的原创深空数学解谜游戏。零 npm 第三方依赖，使用原生浏览器模块 + Node.js 标准库提供网页服务。

## 启动

```bash
cd ~/Downloads/star-array-v0.1
./start.sh
```

访问 **http://localhost:3200**。

如果 3200 端口被占用，先确认旧进程，也可使用：

```bash
PORT=3201 ./start.sh
```

关闭游戏服务器：在启动终端按 Ctrl+C。关闭浏览器不会停止服务器。

## 第一阶段已实现

- 3×3、5×5、7×7 星阵，点击节点翻转自己和上下左右（GF(2)）。
- 十二个预设关卡及可解的随机挑战。
- 真实 GF(2) 高斯消元、解空间维数和最少点击搜索。
- 显示矩阵及行变换过程，提示、解法、撤销、重做、重置。
- 深空风 UI、简体中文 / English、面板左右切换、两种主题、低动画模式。
- 本地浏览器保存关卡最佳成绩和界面偏好（localStorage）。
- 响应式浏览器界面，供电脑与手机试用。

## 数学说明

令 b 为当前状态向量，A 为影响矩阵，x 为点击向量，则解谜等价于 Ax=b (mod 2)。消元可找出一组解及零空间基底；如果自由变量个数不超过 18，枚举全部自由变量组合以证明最小汉明重量。若超过该限制，UI 只会显示“可行解”，不宣称已经证明最优。
