# 10｜沉浸式全屏 UI、课程、双语与设置

## 全屏交互原则

大厅主要负责选游戏；进入后棋盘/实验区域占据浏览器可用视口。桌面不使用长期占据左右宽度的三栏强制布局，课程和算法面板改为按需打开的抽屉。提供返回大厅及退出全屏的稳定控制，浏览器全屏通过 Fullscreen API 请求，按 Esc 返回。手机端不应产生横向溢出。

~~~mermaid
flowchart LR
  A[游戏大厅] --> B[选中游戏]
  B --> C[全视口游戏]
  C --> D[课程抽屉]
  C --> E[算法抽屉]
  C --> F[设置/中英切换]
  C --> A
~~~

## 技术分界

`hub/public/index.html` 与 `hub/public/assets/main.js` 负责大厅导航、iframe 容器、全屏按钮；各游戏自身控制棋盘尺度和状态。大厅语言与主题偏好可写入 localStorage，但不等于五个子应用自动实现一致的完整中英词库。

## 课程与 AI

| 游戏 | 课程/可视化 |
|---|---|
| 围棋 | 50 课、棋谱方法论、评分因素热力图 |
| 五子棋 | 12 课、四方向棋形与候选点解释 |
| 星阵 | 12 关、GF(2) 消元和可行/最优解解释 |
| 扫雷 | 12 课、确定性推断、数字约束 |
| 混沌光轨 | 10 课、像素检测、预测、KF、匈牙利、YOLO 训练概念 |

## 建议统一设置契约（未来）

`language, theme, panelSide, uiScale, sound, motionReduction, contrast`。至少提供中英文、左右侧边栏、音效独立开关、恢复默认；设置不得改变算法结果或删存档。重要操作需明确反馈；不可逆操作二次确认。新增功能需桌面/移动双尺寸和键盘/触屏测试。
