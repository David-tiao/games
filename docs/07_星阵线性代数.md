# 07｜星阵：GF(2) 线性方程组、零空间与最少点击

## 玩法与源码

主要在 `apps/star-array/shared/math.js` 与 `levels.js`。3×3、5×5、7×7 二值棋盘；点击一个节点会翻转自身与上下左右邻点，棋盘不环绕。目标是让所有激活节点熄灭，支持撤销、重做、关卡及随机可解题。

## 数学建模

棋盘状态向量 b，点击向量 x，每格为 0 或 1。影响矩阵 A 的每列表示点击对应节点翻转的格子。要求：

\[
Ax=b \pmod 2
\]

其中加法使用 XOR，重复点击抵消：x ⊕ x=0。影响矩阵可使用 BigInt/位掩码表示，适合小棋盘 GF(2) 消元。

## 高斯消元与零空间

对增广矩阵 [A|b] 执行 XOR 行变换，找主元列并做消元。若某行左边全零、右边为 1，则方程无解；否则可得特解 x0 和零空间基 z1…zk：

\[
x=x_0\oplus c_1 z_1\oplus\cdots\oplus c_k z_k,\quad c_i\in\{0,1\}
\]

~~~mermaid
flowchart TD
  B[棋盘二进制状态] --> A[建立影响矩阵]
  A --> G[GF2 行消元]
  G --> S{是否可解?}
  S --否--> NO[无解说明]
  S --是--> X[特解与零空间基]
  X --> K{零空间维数可枚举?}
  K --是--> GRAY[Gray Code 枚举解]
  K --否--> FEASIBLE[仅报告可行解]
  GRAY --> OPT[汉明重量最小解]
~~~

## 最少点击搜索

点击次数对应二进制向量的汉明重量。若零空间维度 k 不大，可枚举 2^k 种组合，用 Gray Code 使连续候选仅变动一个基向量，再统计最小汉明重量。**只有完整枚举时才宣称严格最优**；超过预算需明确标为可行解。

## 可解关卡生成与验证

先随机选择点击向量 x，再令 b=Ax，就保证新关卡有解。测试：同一格点击两次状态复原、点击次序可交换、求解器返回解能够将棋盘还原、零空间不同解满足同一方程、最优性报告与实际枚举相符。
