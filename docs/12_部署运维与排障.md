# 12｜Linux 启动、部署、备份与排障

## 仓库位置和启动

本机早期 ZIP 解压目录通常为 `~/Downloads/four-games-hub`；使用 GitHub clone 后目录通常为 `~/games`。实际路径以 `pwd` 为准，启动命令 `games` 只是本机脚本指向的目录。

~~~bash
git clone https://github.com/David-tiao/games.git
cd games
./start.sh
# 本机打开 http://localhost:3300
# Ctrl+C 停止
~~~

可选安装 `games` 快捷命令：`./scripts/install-launcher.sh`，重新开启终端后执行 `games`。不需要重复启动已运行的同一端口服务。

## 端口占用

出现 `EADDRINUSE` 或 3300 已占用时，先识别原服务：

~~~bash
sudo ss -lntp '( sport = :3300 )'
~~~

确认进程身份后优雅关闭，或使用 `PORT=3301 ./start.sh`，不要无差别杀死所有 Node 进程。3300 只应是对外入口，围棋/五子棋的子进程绑定本机回环地址。

## 局域网访问

朋友与服务器在能互访的网络时，使用 `http://当前主机IP:3300`。运行 `hostname -I` 核对 IP。局域网私有地址不能让公网直接访问。公网需要 HTTPS/WSS 反向代理、认证、限流及防火墙规则。

## 构建、Python 和降级

首次启动需要 Node.js ≥20、npm 及围棋/五子棋 npm 依赖；启动脚本会检查/安装并构建客户端。混沌光轨浏览器演示不依赖 Python；需要真实检测/追踪时运行 `./scripts/install-ball-tracker.sh` 并重启大厅。没有训练权重时不会自动获得 YOLO 功能。

## 账号备份与迁移

在游戏停止后备份 `apps/go-online/server/data` 与 `apps/gomoku-online/server/data`，将备份放到私有目录。旧目录迁移脚本只负责拷贝和检查，**文档更新不应调用清理脚本**。禁止将 `users.json`、密码哈希、`.env`、日志私密信息提交到公开仓库。

## 故障速查

| 现象 | 首查 |
|---|---|
| 大厅打不开 | `ss -lntp`、终端报错、3300 监听 |
| 只有某个棋类打不开 | 内部服务启动日志、React 构建、网关 502/503 |
| 真人能登录但不同步 | Socket.IO upgrade 路由及身份令牌 |
| 视觉算法不可用 | Python venv、cv2/NumPy/SciPy、`/play/balls/health` |
| YOLO 不生效 | 权重 `best.pt` 是否存在、模式配置 |
| 更新后仍是旧页面 | 强制刷新浏览器、检查实际启动目录 |
