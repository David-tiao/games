# 11｜测试体系、质量门禁与验收清单

## 运行命令

从仓库根目录：

~~~bash
npm run check
npm test
~~~

单独测试星阵：

~~~bash
cd apps/star-array && npm test
~~~

安装了 Python 视觉环境后：

~~~bash
apps/neon-ball-lab/.venv/bin/python -m pytest -q apps/neon-ball-lab/tests
~~~

## 测试分层

~~~mermaid
flowchart TD
  E2E[浏览器端到端：桌面/手机/真人联机] --> API[HTTP/WebSocket/会话集成]
  API --> M[规则与算法单元/性质测试]
  M --> STATIC[JS 语法 / TypeScript / Vite 构建]
~~~

- **围棋**：气、提子、自杀、历史重复、计分、房间权限、AI 评分。
- **五子棋**：四方向五连、边缘、不合法落子、防守强制落点、断线重连。
- **星阵**：相同点击两次抵消、顺序交换、求解一致性、最少步证明。
- **扫雷**：精确雷数、首击和周围格安全、标旗逻辑、约束传播不得读取隐藏数据。
- **混沌光轨**：目标检测、卡尔曼预测、关联门控、轨迹出生/失踪、不同会话隔离。
- **统一大厅**：所有路由、全屏开关、移动端布局、反向代理、服务故障降级。

## 稳定版发布门禁

1. 所有算法单元测试通过；
2. TypeScript `tsc --noEmit`、Vite 正式构建通过；
3. 浏览器真实点击/撤销/教程切换可用；
4. 两台设备验证真人对局、Socket.IO 断线恢复；
5. 保存数据备份、重启后账号重新登录；
6. ZIP 完整、版本号与文档一致；
7. 安全审查无真实账号、明文密钥或模型私有权重。

**测试结果必须记录实际执行的命令、环境、成功/失败数和已知未验证项**。不能把代码语法检查当作完整的浏览器验收，也不能将模拟并发测试宣传成十名真人测试。
