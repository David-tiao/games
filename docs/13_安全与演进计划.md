# 13｜安全、技术债与下一阶段演进

## 已实现与未实现的边界

当前五个入口共享 3300 网关，围棋和五子棋拥有各自的账号及服务器权威对局。**尚未实现**：跨五款统一登录、统一服务端进度保存、保存后 168 小时自动删除、星阵十人同房间合作、生产级公网身份保护。

## 主要资产与威胁

| 资产 | 威胁 | 建议 |
|---|---|---|
| 账号 `users.json` | 泄露、误提交 | .gitignore、最小权限、私有备份 |
| 会话 token | 截获、重放 | HTTPS/WSS、会话失效、速率限制 |
| 房间状态 | 越权操作、重放消息 | 服务端逐条校验身份/回合/序号 |
| Python 图像接口 | 大请求/高并发耗尽资源 | 限制请求大小、频率和并发 |
| 升级脚本 | 覆盖/删除账号 | 更新前备份、禁止自动清理旧目录 |

### 安全边界图

~~~mermaid
flowchart LR
  B[不可信浏览器] --> TLS[未来 HTTPS/TLS]
  TLS --> GW[3300 网关与限流]
  GW --> AUTH[围棋/五子棋独立认证]
  AUTH --> GAME[服务端权威规则]
  GW --> PY[Python 图像大小/并发门禁]
  GAME --> DATA[私有账号存储]
~~~

当前局域网 HTTP 不意味着安全公网部署完成；GitHub 仓库公开不代表应该上传账号、密码哈希、真实存档和密钥。

## 建议演进顺序

1. **安全与质量**：固定依赖、CI 测试、日志脱敏、浏览器 e2e、备份恢复。
2. **统一身份**：整合旧账号、用户 ID 映射、登录迁移，不破坏原账户。
3. **服务端存档**：引入数据库、schema_version、写入时计算 168h 过期、定时清理、读取时检查。
4. **十人星阵协作**：权威房间、操作序号、状态快照、候选标记、断线恢复、撤销投票。
5. **算法研究升级**：围棋/五子棋搜索、扫雷完整约束求解、MOT 数据集与指标、YOLO 模型训练对照。

每项改造必须附代码位置、测试、已知限制和文档修订日期。
