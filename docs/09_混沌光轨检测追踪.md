## 物理模拟

浏览器支持多个小球运动、边界/球间碰撞、尾迹和颜色变化。质量近似随半径平方变化，弹性系数约 0.90。周期换色意味着颜色不宜作为稳定目标身份。动画不是检测结果本身。

## 单目标常加速度 KF

状态 X=[px,py,vx,vy,ax,ay]ᵀ；位置预测：

\[
p'_x=p_x+v_x\Delta t+\tfrac12a_x(\Delta t)^2,\quad
v'_x=v_x+a_x\Delta t
\]

y 轴同理。测量为像素位置 z=(x,y)。Kalman 预测与修正：

\[
\hat x^-=F\hat x,\quad P^-=FPF^T+Q,\quad
K=P^-H^T(HP^-H^T+R)^{-1},\quad
\hat x^+=\hat x^-+K(z-H\hat x^-)
\]

噪声与协方差更新影响平滑性、预测误差和碰撞后重新收敛速度。

## 多目标常速度 KF 和 Hungarian

`mot_core.py` 每轨迹保存 ID、状态、协方差、半径、命中次数、缺失时间等。状态 X=[px,py,vx,vy]ᵀ。先预测，再用马氏距离平方进行门控：

\[
d^2=(z-H\hat x^-)^TS^{-1}(z-H\hat x^-)
\]

当前门控阈值约为 16。代价兼顾位置、半径与检测置信度：

\[
C_{ij}=d_{ij}^2+2.5\left|\log(r_j/r_i)\right|+0.7(1-s_j)
\]

使用 `scipy.optimize.linear_sum_assignment` 分配一对一匹配，并允许轨迹不匹配，避免强行关联到错误球。

| 参数 | 典型默认值 | 意义 |
|---|---:|---|
| `min_hits` | 2 | 确认轨迹前的命中要求 |
| `max_missing` | 1.1 秒 | 缺失后暂存 |
| `max_tracks` | 20 | 内部轨迹上限 |
| `measurement_sigma` | 7 px | 位置测量噪声 |
| `acceleration_sigma` | 950 | 机动过程噪声 |
| `gate` | 16 | 匹配门控 |
| `future_seconds` | 0.35 秒 | 短时预测 |

靠近其他轨迹时会提高过程噪声以适应可能碰撞，但**并不直接读取浏览器中的碰撞真实事件**。

## 会话隔离和性能边界

浏览器通过网关向本机 Python `/frame` 提交 JPEG，响应返回检测/追踪状态。`local_server.py` 按会话保存独立估计器并清理长期未访问的会话（约 120 秒）；这是 ID 隔离而非十人共享游戏房间。YOLO 无权重时不能冒充神经网络推理；`hybrid` 和 `classical` 模式应准确标明实际检测来源。

## 科学评价

单球跟踪 RMSE 与多目标 MOT 指标不可混用。多目标应考虑 ID switches、IDF1、MOTA/HOTA、检测 Precision/Recall。预测 0.35 秒未来位置时，应与对应未来时刻真值比较，且控制输入帧率、随机种子和遮挡条件。详细算法推导见 `apps/neon-ball-lab/ALGORITHMS.md`。
